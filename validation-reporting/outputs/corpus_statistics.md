## Why the work populations differ

- **Manuscript/Toupin count: 3,532 works.** The current core file has 3,541 unique OpenAlex IDs. Across its non-missing titles, 8 exact-title groups contain multiple IDs and contribute 9 excess ID-level records. Deduplicating those exact non-missing titles, while retaining the 6 records whose title is `NA` separately, yields exactly 3,532 records. This is concrete evidence consistent with title-level counting, but it is not proof of the manuscript's original procedure because no manuscript-level ID list is available locally.
- **`openalexworks.json`: 3,446 unique IDs.** Its ID set is a strict subset of the current core ID set: 95 core IDs are absent from the metadata JSON, while 0 JSON IDs are absent from the core file.
- **`core_works.csv`: 3,541 unique IDs.** The archived pipe-delimited core file has 3,542 unique IDs. The current file removes exactly 1 archived ID (https://openalex.org/W4372171628), matching `data/removedRow.txt`.

The complete 95-ID set difference, repeated-title groups, and archived removal are in `population_id_differences.csv`.

## Sampling protocol

- Sample size: 100 mention instances per CSV.
- NER validation seed: 20260821.
- Canonical-region validation seed: 20260822.
- Algorithm: Sort by mention_instance_id, then Mulberry32-seeded Fisher-Yates without replacement.
- Context: up to 200 source characters on each side; `[[...]]` marks the sampled mention.
- Sampling is without replacement within each sample, enforced using `mention_instance_id` uniqueness.

## Evaluation scope

Recall is not estimated because undetected geographic references are not exhaustively annotated. The evaluation utility reports counts and denominators for every percentage.
